# Current Task

## Objective

修复退款、微信 XLSX 导入时间和流水保存失败提示，并保持数据库 schema、金额存储规则以及导入导出格式不变。

## User Requirements

- 流水编辑保存失败使用弹窗，保留草稿并提供“返回修改”。
- “公费垫付”和“代收代付支出”允许退款；退款金额继续以正数保存，特殊分类退款反向冲减对应指标。
- Excel 返回的 Date 使用 UTC 字段还原原始表格时间；普通 CSV 时间解析保持原行为。
- 普通退款以负贡献参与个人概览的支出、结余、趋势、分类、标签和年度汇总。
- 概览饼图只保留正净额；负净额分类和标签在图下显示为可打开明细的列表。
- 概览中的退款显示负号；流水列表、导入预览和 CSV 导出继续保持退款正数语义。
- 待报销退款进入待报销清单并显示正数，已报销退款不进入清单。

## Constraints

- 不修改数据库 schema、migration、金额存储规则、导入导出格式或本地优先架构。
- 不自动修正已经写入数据库的历史微信错误时间，只修复后续导入。
- 不读取、覆盖或上传真实数据库、备份、导出文件或账务内容。
- 页面加载错误继续使用页面错误状态；本次弹窗只覆盖流水编辑/保存错误。
