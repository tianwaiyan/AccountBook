# AccountBook

AccountBook 是一款面向个人和家庭使用的 Windows 本地记账软件。它强调**快速记录、清晰整理和数据掌控**，不需要注册账号，也不依赖网络。

## 软件特色

### 本地保存，数据掌控在自己手中

- 账本数据保存在软件所在文件夹中，不自动上传云端。
- 不需要登录，不依赖服务器，断网时也可以正常记账。
- 软件和数据可以一起复制到其他文件夹或电脑中使用。

### 打开即用的便携体验

- 不需要安装程序，双击 `AccountBook.exe` 即可运行。
- 软件默认以最大窗口打开，适合查看完整流水和统计图表。
- 窄窗口下会自动切换为更紧凑的布局，常用操作仍然方便访问。

### 适合快速记账和集中整理

- 使用“记一笔”快速记录日期、账户、收支、金额、分类、标签和备注。
- 可在“选项管理”的“月度预设”中设置工资、房租等固定账目，并在流水列表中批量记账。
- 账户、分类、标签和状态可以统一管理。
- 支持修改、复制、删除和批量修改流水，减少重复操作。

### 流水列表清晰、灵活

- 支持按月份、关键词、账户、收支、分类、标签、状态和金额范围筛选。
- 时间和金额支持升序、降序和取消排序。
- 长按表头可以调整列顺序，拖动列边缘可以调整列宽。
- 备注、交易对方等较长内容会自动收起，悬停或展开时可以查看完整内容。
- 修改流水时先在草稿中编辑，确认保存后再写入账本，降低误操作风险。

### 账单导入更省时间

- 支持支付宝 CSV/XLSX 账单。
- 支持微信 CSV/XLSX 账单。
- 支持标准 CSV 导入和导出。
- 导入前可以预览记录、检查金额和分类，并识别重复流水。
- 无法确认的来源分类会保留原始信息，方便后续处理。

### 概览信息一目了然

- 查看月度收入、支出、结余和交易数量。
- 通过趋势图了解不同月份的变化。
- 通过分类和标签统计，快速找到主要支出方向。
- 待报销、待转出等需要处理的流水会集中显示。

## 开始使用

1. 将 `AccountBook.exe` 放在一个普通且具有写入权限的文件夹中。
2. 双击 `AccountBook.exe` 启动软件。
3. 首次启动会自动创建数据目录和数据库。
4. 先在“选项管理”中确认账户、分类和标签，再开始记账或导入账单。

建议使用类似 `D:\AccountBook` 的目录。不要直接从压缩包内部、临时目录、只读磁盘或受保护的系统目录运行。

## 数据和备份

软件会在应用程序所在目录保存以下内容：

```text
AccountBook.exe
data/
  AccountBook.db       # 账本数据库
  webview/              # 界面运行数据
backups/                # 默认备份目录
```

- 数据库固定为 `data/AccountBook.db`。
- 首次启动时会自动创建 `data`、`backups` 和数据库文件。
- “创建完整备份”默认保存到 `backups`，也可以选择其他位置。
- 恢复备份前会检查文件完整性，并自动创建回滚备份。
- 设置中的“退出时清理 WebView2 浏览数据”只清理缓存、Cookie 和站点数据，不会删除账本或备份。
- 移动软件时，请同时移动 `AccountBook.exe`、`data` 和 `backups` 文件夹。

## 运行要求

- Windows 10 或 Windows 11
- Microsoft Edge WebView2 Runtime
- 软件所在目录具有写入权限

如果启动时提示目录不可写，请把整个软件文件夹移动到具有写入权限的位置后再启动。软件不会把数据偷偷改存到 AppData 或其他位置。

## 隐私提示

AccountBook 当前完全离线运行。请不要把 `data/AccountBook.db`、`data/webview`、`backups` 中的真实备份或账单文件上传到公开平台。
